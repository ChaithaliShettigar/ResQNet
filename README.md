# ResQNet Features

ResQNet helps community members report emergencies and helps response teams review and coordinate incident response.

## Community features

- **Emergency reporting:** Submit an incident with its type, description, severity, location, contact number, and an optional photo.
- **Voice input:** Record a description and transcribe it into the report form.
- **AI analysis:** Review an urgency level, explanation, confidence score, and details that may need follow-up. Safety checks help keep urgent reports from being assigned a lower priority.
- **My Reports:** View submitted reports and follow their status.
- **Public incident map:** Browse public incidents, filter them by urgency, and confirm incidents you believe are real.
- **Report tracking:** Look up a report using its reference number.
- **AI Follow-Up Calls:** Review simulated follow-up calls, answer questions, and request a return call to confirm report details.
- **Notifications:** View account notifications and report updates.
- **Profile & Settings:** Manage profile information and notification preferences.

## Language and accessibility

- **Multilingual translation:** Translate incident descriptions and response instructions into supported languages while keeping the original text available.
- **Speech playback:** Listen to supported text read aloud.
- **Language-aware reporting:** Keep the source language associated with a transcribed report.

## Response team features

- **Incident overview and queue:** Review incidents, their urgency, status, and reported details.
- **Incident map:** See incidents by location to support response planning.
- **Verification:** Review reports and identify information that needs confirmation.
- **Follow-up calls:** Review call status and follow-up needs.
- **Response coordination:** View response coordination information for incidents.
- **Weather context:** Review weather information associated with incident monitoring.
- **Administration and permissions:** Access administration tools for authority accounts.
- **Incident updates:** Manage incident status and response information through the authority dashboard.
